# Applied Econometrics with Stata

A portfolio of applied econometrics projects implemented in Stata, covering demand estimation, panel-data models, binary-response models, sample selection, discrete choice, and causal inference.

## Projects

| Project | Methods | Key Topic |
|---|---|---|
| [01 Demand System Estimation](./01_Demand_System_Estimation) | LA-AIDS, IV, GMM, elasticities | Consumer demand |
| [02 Firm Productivity Panel Analysis](./02_Firm_Productivity_Panel_Analysis) | Pooled OLS, FE, RE, System GMM | Firm productivity and exports |
| [03 Binary Response and Sample Selection](./03_Binary_Response_and_Sample_Selection) | LPM, Probit, Heckman selection | Arrest outcomes and wages |
| [04 Discrete Choice and Causal Inference](./04_Discrete_Choice_and_Causal_Inference) | Conditional logit, PSM, DiD, event study, RDD | Consumer choice and policy evaluation |

## Econometric Methods

- Panel-data estimation
- Fixed and random effects
- Instrumental variables
- Generalized Method of Moments
- Dynamic panel System GMM
- Binary-response models
- Sample-selection correction
- Alternative-specific conditional logit
- Propensity-score matching
- Difference-in-differences
- Event-study analysis
- Regression discontinuity design
