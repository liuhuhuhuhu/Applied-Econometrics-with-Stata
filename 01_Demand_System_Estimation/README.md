# Demand System Estimation

## Overview

This project implements the Almost Ideal Demand System (AIDS) using Stata to estimate consumer demand behavior from product-level market data.

The workflow includes:

- Data preparation and cleaning
- Budget share construction
- Stone Price Index
- Linear AIDS (LA-AIDS) estimation
- Instrumental Variables (IV)
- Two-Stage Least Squares (2SLS)
- Generalized Method of Moments (GMM)
- Exact AIDS iterative estimation
- Price and income elasticity analysis
